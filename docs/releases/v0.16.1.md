0.16.1 is a bug-fix release, with one small addition to Settings. It changes nothing you need to set up: speck watches your builds calmly instead of jumping from one thing to the next, trackpad swipes between lanes keep working without a click in between, and the dot by speck's name tells you whether Auto-build is on.

## What's fixed

- **A calmer speck.** While builds run, speck now mostly sits and watches, for 15 to 35 seconds between each thing it does, and its comic moments and TV tricks come at most once every two minutes. Each TV's bar takes longer to fill, and speck hops at most once every 30 seconds. Before, one thing followed straight after another and speck hopped every few seconds, which made it tiring to watch.
- **Trackpad swipes keep working.** Swiping sideways on a laptop trackpad changes lane between Plan, Build and Shipped swipe after swipe, including in a narrow Cursor browser pane. Before, after one swipe the next did nothing until you clicked the panel. One long glide still changes lane only once.
- **A dot that means something.** The dot before "speck" in the header is red while Auto-build (`speck run`) is on and grey while it's off, like a power light. Before, it was always red, so it looked live even when nothing would build.
- **Same-model review from Settings.** `allow_same_model_review` is now a switch beside the reviewer's settings rather than read-only, so you no longer have to edit `speck/config.yml` to let a reviewer run the same model as the builder. Turning it on asks first, because such a review is no longer independent, and it's saved for this machine only.

## Update

Paste the setup prompt from the README into your coding agent, or run this in each project's folder:

```sh
npx github:luroai/speck#v0.16.1 init
```

## Upgrading from 0.16.0

- Run `npx github:luroai/speck#v0.16.1 init` again in each project to update the speck command and skills. It keeps your config and tickets.
- There are no new settings, so nothing needs adding to `speck/config.yml`. Turning `allow_same_model_review` on in Settings saves it for this machine, alongside your builder and reviewer, rather than in `speck/config.yml`.

See everything that's changed in the [0.16.1 section of the changelog](https://github.com/luroai/speck/blob/v0.16.1/CHANGELOG.md#0161--26-october-2026).
