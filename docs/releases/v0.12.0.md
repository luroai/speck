0.12.0 is a minor release that reworks the panel for narrow panes, such as the browser pane in Cursor or the Claude desktop app. A finished document task is now a short, calm row, its document opens in a pop-up over the whole panel that you can ship it from, the header stays on one row with the project always in view, and the Foreman's status scrolls across a dot-matrix notice board. It matters because the panel is where you read work and decide whether to ship it, and in a narrow pane it used to crowd that out.

## What's new

- **A calm row for a finished document.** When a document task's build has finished, its queue row says "Finished · read the document" and has a Review pack button, in place of a "Build finished without shipping" line and the end of the build's log.
- **Documents in a pop-up.** A Markdown document opens over the whole panel window, in a centred column, rather than in the narrow side pane. Close or Escape takes you back to the review pack.
- **Ship from the document.** When the ticket is approved, the pop-up has Ship and Ask for changes above the document, working exactly as the review pack's do, so you can read and decide in one place.
- **A one-row header.** In a narrow window, the header no longer changes as you scroll. It always shows the project and base branch, cut short with an ellipsis if they don't fit, and speck's logo shows once.
- **The Foreman's notice board.** The Foreman's button is a dot-matrix screen that shows its word and what each ticket in flight is doing, scrolling when that's too long to fit. It keeps its colours, so Needs you is still red. Pressing it opens the Foreman's detail in a pop-up that stays in view, rather than under the header.

## Update

Paste the setup prompt from the README into your coding agent, or run this in your project's folder:

```sh
npx github:luroai/speck#v0.12.0 init
```

## Upgrading from 0.11.0

- Run `npx github:luroai/speck#v0.12.0 init` again in each project to update the speck command and skills. It keeps your config and tickets.
- There are no new settings in `speck/config.yml`, and nothing changes in how tickets are built, reviewed or shipped. Only the panel looks and works differently.
- A panel page that's already open notices the new page, and its Foreman's button says Reload page: reload it to see the changes.
- If your device asks for less motion (`prefers-reduced-motion`), the notice board never scrolls and shows the Foreman's word alone.

See everything that's changed in the [0.12.0 section of the changelog](https://github.com/luroai/speck/blob/v0.12.0/CHANGELOG.md#0120--22-october-2026).
