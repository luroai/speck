0.13.1 is a bug-fix release. A build you stop starts again once its ticket is set ready and committed, without restarting `speck run`. A test that fails once and passes on a second try no longer sends a ticket back to its build. `speck doctor` checks that Cursor's CLI is installed when Cursor reviews, and a pop-up's Close button stays in view while it scrolls. Nothing changes in your config or the commands.

## What's fixed

- **A stopped build starts again by itself.** After `speck stop`, setting the ticket ready and committing it is enough: the `speck run` that's already going starts it on its next check. Before, nothing started until you restarted `speck run`.
- **Chance failures don't send a ticket back.** When a ship's tests fail, the failing ones run once more. A test that passes on that second try is no longer named in the refusal, and `speck run` no longer hands the ticket back to fix a test that isn't broken. Tests that fail both times still do.
- **`speck doctor` checks a Cursor reviewer.** With Cursor reviewing and no review command of your own, doctor checks that `agent` or `cursor-agent` is installed and says how to install it, so you find out before the first review fails rather than when it does.
- **Close stays in view.** A document's pop-up keeps its path and Close at the top while the document scrolls, and Settings and the Foreman's pop-up keep Close at the top too. On a phone, where there's no Escape key, you no longer have to scroll back up to close one.

## Update

Paste the setup prompt from the README into your coding agent, or run this in each project's folder:

```sh
npx github:luroai/speck#v0.13.1 init
```

## Upgrading from 0.13.0

- Run `npx github:luroai/speck#v0.13.1 init` again in each project to update the speck command and skills. It keeps your config and tickets.
- Nothing else changes: no settings or commands are added or renamed.

See everything that's changed in the [0.13.1 section of the changelog](https://github.com/luroai/speck/blob/v0.13.1/CHANGELOG.md#0131--23-october-2026).
