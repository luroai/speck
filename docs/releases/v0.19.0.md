0.19.0 shows you what your AI work costs. speck now records the tokens and cost of every build, review round and watch agent run, whichever agent and model did it, shows each shipped ticket's total cost in the panel, and adds it all up with a new `speck spend` command. Before, you saw only what a Claude Code builder cost, and nothing for reviews, Codex or Cursor.

## What's new

- **A price table in every release.** speck now carries a list of what each AI model charges, taken from LiteLLM's public price list on the day of the release, so it can put a cost on agents that report only tokens, such as Codex and Cursor. It never goes online for prices. `speck prices <model>` shows the rates it would use for a model and the date they were taken.
- **Every review round has a cost.** Each round now saves the model it ran on, its tokens and its cost. Before, rounds kept their tokens but no cost, so a ticket's spend left its reviewer out altogether.
- **Every build has a cost, model by model.** Each build saves which models did the work and what each cost, and Codex and Cursor builds are priced for the first time. A ticket built more than once now counts every build, not just the last, and a Cursor build no longer counts reused prompt text twice.
- **The watch agent's spend counts too.** What speck's own agent spends looking into a stopped ticket is now kept against that ticket instead of being lost on its next run.
- **Total cost in the panel.** A shipped ticket shows its reviewer cost and total cost beside its builder cost, and its card shows the total. When part of it has no known price, the total says "at least" and its tooltip says what's missing, so you're never shown a figure that looks complete but isn't.
- **`speck spend`.** One command adds up what your tickets have cost, by ticket, model, week or month, over any range of days, or as JSON. Before, you had to add each ticket's figures by hand.
- **`speck spend --backfill`.** Recovers spend from before this release: earlier builds and watch agent runs from the conversation records Claude Code keeps on your machine, and earlier review rounds from the tokens they saved.

Costs speck works out from tokens are estimates at API list prices, so they can differ a little from what you were billed. A cost speck can't work out, such as one on Cursor's `auto`, shows as unknown, never $0.

## Update

Paste the setup prompt from the README into your coding agent, or run this in each project's folder:

```sh
npx github:luroai/speck#v0.19.0 init
```

## Upgrading from 0.18.0

- Run `npx github:luroai/speck#v0.19.0 init` again in each project to update the speck command and skills. It keeps your config and tickets.
- Run `speck spend --backfill` once in each project after updating, to recover spend from before 0.19.0. It's safe to run again: spend it has already counted isn't added twice. Claude Code deletes its conversation records after 30 days by default (its `cleanupPeriodDays` setting), so builds older than that can't be recovered: run it soon.
- Tickets shipped before 0.19.0 show "—" for costs that weren't recorded, until the backfill fills in what it can.
- There are no new settings, so nothing needs adding to `speck/config.yml`.

See everything that's changed in the [0.19.0 section of the changelog](https://github.com/luroai/speck/blob/v0.19.0/CHANGELOG.md#0190--27-october-2026).
