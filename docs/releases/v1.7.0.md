1.7.0 is a minor release that runs every project on your machine from one speck service. Until now, each project needed its own panel on its own port, started by hand in its own folder, and nothing came back after a restart until someone started it again. Now `speck projects` keeps a list of your projects, and `speck serve` runs them all: a panel for each, its `speck run` kept going, and one address that opens on All projects, on this machine or from your phone. It can start by itself when the machine starts.

## What's new

- **A list of your projects.** `speck projects` lists the projects on this machine, with each one's speck version and whether its panel and `speck run` are on, and `speck projects add` and `speck projects remove` change the list. So speck knows every project you have, whether its panel is running or not.
- **One service for every project.** `speck serve` starts a panel for each listed project, each on that project's own copy of speck from 1.5.0 on, and starts again any that stops. So one command brings up every project, and a panel that falls over comes back by itself.
- **One address for all of them.** `speck serve` answers at `http://127.0.0.1:4777`, and with `--url` at your private tunnel's address, opening on All projects. Choose a project and its own panel opens at the same address, where everything works as it does on its own port. So you can reach every project from your phone, not just the one behind the tunnel.
- **Each project's `speck run` kept going.** `speck serve` turns Auto-build back on in every project that had it on, starts again a run that stops by itself, up to 3 times an hour, and keeps off a run you turned off. So work carries on in every project after a restart without anyone turning it on again.
- **Starts with the machine.** `speck serve --install` sets it up as a systemd user service on Linux, starting at boot, or a launch agent on a Mac, starting when you log in, and `speck serve --uninstall` takes it away. So the panel is reachable and work moves after a restart without starting anything by hand.
- **Leave a project out without forgetting it.** `speck projects off <name>` keeps a project on the list but out of `speck serve`, its panel, its run and All projects, and `speck projects on <name>` brings it back. So a paused side project stays off the factory floor without being added again later.

There are smaller fixes too: answering the reviewer's question at the review limit now lets the build carry on with its 2 extra rounds rather than stopping again, and on a phone the lane lists only scroll up and down, so a sideways swipe always changes lane. The shipped price table has this release's rates. Costs speck works out from tokens are still estimates at API list prices, so they can differ a little from what you were billed.

## Update

Paste the setup prompt from the README into your coding agent, or run this in each project's folder:

```sh
npx github:luroai/speck#v1.7.0 init
```

## Upgrading from 1.6.1

- Run `npx github:luroai/speck#v1.7.0 init` again in each project to update the speck command and skills. It keeps your config and tickets, and nothing in `speck/config.yml` changes.
- Nothing changes until you start `speck serve`: a panel you start with `speck panel` works as before.

## Moving from a panel per project to `speck serve`

1. In each project's folder, run `npx github:luroai/speck#v1.7.0 init` to update it, then `speck projects add` to put it on the list. A project on speck 1.5.0 or later runs under `speck serve` without updating, but on 1.7.0 its Auto-build switch is remembered for `speck serve`.
2. Stop the panels you started by hand, with `speck panel --stop` in each project. `speck serve` leaves a panel you started as it is and doesn't start it again if it stops, and one on port 4777 keeps `speck serve` from starting.
3. Start it: `speck serve --background`, or `speck serve --install` to have it start with the machine. Give it the `--url` you gave the panel behind your private tunnel, so your phone opens every project at that one address.
4. Open `http://127.0.0.1:4777`, or your tunnel's address, and choose a project from All projects. Auto-build stays on in each project that had it on.
5. To keep a project out for a while, run `speck projects off <name>`, and `speck projects on <name>` when you want it back.
