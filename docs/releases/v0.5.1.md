0.5.1 is a patch release of fixes to what 0.4.0 shipped: stopping and restarting builds, build timers, the ship queue's messages, the reviewer's test summary, review packs and the panel.

## What matters most

- **Stopping a build is quick and can be undone.** `speck stop` ends a build within about five seconds, even on a busy machine, and a build stopped before it started its ticket can be built again with `/speck-build <id>`, with no tidying up by hand.
- **Build times leave out waiting.** A stopped build's timer stops until the build starts again, and the review pack's build time stops at approval, so neither counts time spent waiting for you.
- **A ship that merged but wasn't pushed says so.** `speck run`'s log says the ticket was merged but not pushed, and how to push it, instead of promising a retry that never comes.
- **The reviewer sees each failing test once.** A test that fails on both tries of a full run is listed once in the reviewer's test summary, with the whole run's totals.
- **You can see who is at work on a ticket under review.** Its card says which round the reviewer is running, or that the builder is fixing the last round's findings.

## Install

Paste the setup prompt from the README into your coding agent, or run this in your project's folder:

```sh
npx github:luroai/speck#v0.5.1 init
```

## Upgrading from 0.5.0

- Run `npx github:luroai/speck#v0.5.1 init` in your project to update the speck command and skills. It keeps your config and tickets.
- Nothing in `speck/config.yml` needs changing.
- `speck start <id>` now also starts a blocked ticket that has no branch, as it would a ready one, so a build stopped before it started can be picked up again.

See everything that's changed in the [0.5.1 section of the changelog](https://github.com/luroai/speck/blob/v0.5.1/CHANGELOG.md#051--16-october-2026).
