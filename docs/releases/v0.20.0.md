0.20.0 makes a ticket's spend complete when its build hands work out to other agents. Helper agents a Codex build starts, and Codex runs started in a ticket's own folder, such as research a Claude Code builder hands to Codex, now count in what the ticket cost. Before, 0.19.0 left them out, so those tickets looked cheaper than they were.

## What's new

- **A Codex build counts its sub-agents.** A Codex build's tokens and cost now include every sub-agent it started, and theirs in turn, each priced at the model it ran on. Before, only the main thread counted: in one small test, that left out 29% of the tokens. If a sub-agent ran on a model with no known price, the build's cost shows as unknown rather than a figure that's too low.
- **Codex runs in a ticket's folder count towards it.** When a build ends, speck also counts each Codex session that ran in the ticket's worktree, however it was started, for example by a Claude Code builder running `codex exec` itself. The builder doesn't have to do anything special, and nothing is counted twice. The ticket's total cost in the panel includes it, `speck spend` shows it in a Delegated column of its own, and `speck status --json` gives it as `delegated_tokens` and `delegated_cost_usd`.
- **A Claude Code build's sub-agents are checked, not assumed.** Its recorded spend already included the sub-agents it started with the Agent tool. That's now checked against a real build that started two, so you can trust the figure.

Costs speck works out from tokens are estimates at API list prices, so they can differ a little from what you were billed. A cost speck can't work out shows as unknown, never $0.

## Update

Paste the setup prompt from the README into your coding agent, or run this in each project's folder:

```sh
npx github:luroai/speck#v0.20.0 init
```

## Upgrading from 0.19.0

- Run `npx github:luroai/speck#v0.20.0 init` again in each project to update the speck command and skills. It keeps your config and tickets.
- The new counting happens when a build ends, so it applies to builds that end after you update. Tickets already shipped keep the spend they recorded.
- Codex runs in a ticket's folder are only counted for tickets built in their own worktree, which is the default (`worktrees: true`).
- There are no new settings, so nothing needs adding to `speck/config.yml`.

See everything that's changed in the [0.20.0 section of the changelog](https://github.com/luroai/speck/blob/v0.20.0/CHANGELOG.md#0200--27-october-2026).
