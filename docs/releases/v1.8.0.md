1.8.0 is a minor release that gives `speck serve` a factory floor. Until now, the panel was the only view: one narrow column showing one lane of one project at a time, made for a phone or a side panel. On a laptop, seeing what every project was doing meant opening each one in turn. Now `speck serve`'s address has a page for a wide window that shows every project at once: who is working on which ticket and on which model, what needs you, how much of each subscription is used, and a project's whole board side by side. The panel is unchanged.

## What's new

- **A station for every project.** The factory floor shows a numbered station for each project that isn't turned off, with its state, how many tickets are building, queued, need you and shipped this week, and a line of what shipped each day over two weeks. Choosing one lays its Capture, Plan, Build and Shipped out side by side below. So you can see how every project is doing, and a whole board, without switching lanes or projects.
- **The line, with the model on every station.** A row for each project runs through Queue, Builder, Reviewer, QA and Ship. Each station with a ticket on it lights up with the ticket, how long it's been there, the agent, model and effort it's on, and why: its level, its own choice, your settings or a stand-in while an agent is at its usage limit. An idle station shows what it would use next. So you can see at a glance who is working on what, and on what, across every project.
- **Virgil's dial.** Virgil, the engineering manager, sits beside the line in the busiest mood of all your projects, over a count of everything that needs you and a line for each. So one place tells you what's waiting on you, wherever it is.
- **Your subscriptions.** Each agent speck has a usage reading for shows how much of its tightest limit is used, when it resets and how many stations are running on it now, turning orange at 90% or once it's limited. So you can see whether a subscription is about to hold the work up, next to the work drawing on it.
- **Open a ticket from the floor.** Pressing a card on a board or a lit ticket on the line opens that ticket in its project's panel at the same address, and the ticket's back link, or the browser's Back, returns to the floor with the same station chosen. Cards and lit tickets work from the keyboard too, and each line under Virgil's dial opens its ticket in the same way. So you can read or act on any ticket and carry on where you were.

The shipped price table has this release's rates. Costs speck works out from tokens are still estimates at API list prices, so they can differ a little from what you were billed.

## Update

Paste the setup prompt from the README into your coding agent, or run this in each project's folder:

```sh
npx github:luroai/speck#v1.8.0 init
```

## Upgrading from 1.7.0

- Run `npx github:luroai/speck#v1.8.0 init` again in each project to update the speck command and skills. It keeps your config and tickets, and nothing in `speck/config.yml` changes.
- Update every project, not just the one `speck serve` runs from: a project still on an older speck shows "No line from this project" on the line, and its tickets' back links go to its own lane rather than to the floor.
- Then start `speck serve` again from an updated project, so it runs the new release and serves the floor: `speck serve --stop`, then `speck serve --background`. If you installed it with `speck serve --install`, run `speck serve --install` again from an updated project, with the same `--port` and `--url`: it replaces the service and starts it on 1.8.0.

## Opening the factory floor

1. Start `speck serve` if it isn't running, as in 1.7.0.
2. Open its address, `http://127.0.0.1:4777` unless you gave another `--port`, or your tunnel's address, and follow the Factory floor link on All projects. Or add `/floor` to the address.
3. Choose a station to see that project's board, and press any ticket to open it in its panel.

The floor is made for a laptop or desktop window. On a phone, the panel at the same address is still the view to use.
