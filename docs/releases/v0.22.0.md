0.22.0 is the release where speck can decide for you and tell you what it chose. Set `watch: decide` and a build that stops with a question carries on with its own recommendation, the panel lists each choice so you can change it before it ships, and a ticket whose acceptance criteria changed waits for you at Ship. `watch` still starts at `tell`, so nothing decides for you until you turn it on.

## What's new

- **`watch: decide` takes the recommendation.** speck takes the recommendation of any blocked question that has one and resumes the build, whatever the question changes, and notes each choice on the ticket. Most blocked questions end in you pressing Go with the recommendation, so most of them no longer need you. It still waits when there's no recommendation, when the ticket is high risk, or after 3 recommendations on one ticket, and it never raises the size limit for you.
- **The watch agent acts instead of asking.** With `watch: decide`, the agent that looks into a stuck build takes its own recommendation on a low-risk ticket and carries the build on. It asks only when it has none or the ticket is high risk.
- **Decided for you, in the panel.** A line under speck's status says how many recommendations it took in the last 7 days. It opens a list of each one: the ticket, the option, when, and whether its criteria changed. A ticket that's approved and not yet shipped has a Change button, so you can ask for changes before it ships.
- **A size-guard split carries on.** With `watch: fix` or `decide`, a build that goes over the size limit and recommends a split no longer waits for you. It carries on with the first part, and the rest becomes a new ready ticket that runs straight after it. With `decide`, a high-risk ticket's split still waits for you.

## What's changed

- **Changed criteria wait for you.** A ticket whose acceptance criteria differ from the ones it was set ready with no longer ships by itself, even with `auto_ship` on, so nothing ships against criteria you didn't agree to. You can still ship it yourself, and its review pack shows the old and new wording.
- **speck asks about a stop once.** While a question from speck is waiting for you, new commits no longer start another look at that ticket. Before, the same question could be asked again and again.
- **speck notices a build that runs long.** When a build has run for more than twice the usual time, and at least 20 minutes, the watch agent looks into why and tells you what it found, or raises a draft fix ticket if the base branch is broken. With `watch: tell`, `speck run` only says so in its log. Before, a hanging test could go unnoticed until someone asked.
- **`speck doctor` says whether the commit check is on.** A project set up before 0.21.0, or one whose pre-commit hook was replaced, has no check on its commits, and until now nothing said so. It's a warning, never a failure, and it leaves your own hook alone.
- **Lint is now the ready check.** The command is `speck check <id>`, and the panel's list on a draft is headed Ready check, because "lint" didn't say what it checks.
- **Steadier tests.** Two more of speck's own tests no longer fail by chance on a busy machine, so fewer finished tickets are handed back at ship for nothing.

The shipped price table has this release's rates. Costs speck works out from tokens are still estimates at API list prices, so they can differ a little from what you were billed.

## Update

Paste the setup prompt from the README into your coding agent, or run this in each project's folder:

```sh
npx github:luroai/speck#v0.22.0 init
```

Then, to try speck deciding for you, pick `decide` under Watching in the panel's Settings view, which sets `watch: decide`, or run `speck config set watch decide`.

## Upgrading from 0.21.1

- Run `npx github:luroai/speck#v0.22.0 init` again in each project to update the speck command and skills. It keeps your config and tickets. The new skills are what let a build mark a size-guard block and let the watch agent use `decide` and `tell`.
- `speck lint` is now `speck check`, and `speck lint` still works, with the same results and exit codes. The `lint` fields in `speck status --json` keep their names.
- There are no settings to add to `speck/config.yml`. `watch` gains the value `decide`, and it still starts at `tell`.
- If you already use `watch: fix`, you'll see two changes without touching a setting: a recommended size-guard split is taken for you, and the agent looks into builds that run long.
- If you use `auto_ship`, a ticket whose acceptance criteria changed now waits for you at Ship rather than shipping by itself.
- `speck doctor` may now warn that the commit check is off. Running `init` again adds it unless you have your own pre-commit hook, in which case `speck doctor` says so and leaves it alone.

See everything that's changed in the [0.22.0 section of the changelog](https://github.com/luroai/speck/blob/v0.22.0/CHANGELOG.md#0220--9-november-2026).
