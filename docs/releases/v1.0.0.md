1.0.0 is the release where speck becomes your engineering manager. You decide what gets built and what done looks like. speck gets it shipped: it runs the builder and reviewer you chose, makes the obvious calls, looks into work that gets stuck and tells you what it did, asking you only when there's no clear answer. You can give it a name of your own, and the panel is redesigned around it, from a black bar with speck's new face to a view of every project on your machine at once.

## What's new

- **Your engineering manager, by name.** A new `speck_name` setting names it, in Settings under Your engineering manager or with `speck config set speck_name "<name>"`. It goes by that name wherever it speaks or acts: on a blocked ticket, in its questions, in Decided for you, in `speck status` and in `speck run`'s log, where it speaks in the first person. So it's clear which choices were the manager's and which were yours.
- **The black bar and speck's face.** The LCD screen is gone. A black bar shows speck, what it's doing, the project and its branch, and what's queued and needs you, without cutting the status short on a phone. speck's face, a small device with a red visor, shows its mood at a glance: asleep, watching, focused, asking when something needs you, pleased when a ticket ships, sheepish beside changed criteria. The app icon is the same character.
- **Lanes you can read on a phone.** Capture, Plan, Build and Shipped are tabs with their counts, and each lane is a list of short rows, so far more fit on a small screen. Build groups them under Needs you, Building and Queued, and a build that stopped and won't be picked up now counts as needing you. You can set a draft ready from its row, and Shipped opens with its figures.
- **A full view for every ticket.** Each ticket opens to one page: how far it has got, its facts, its criteria with the reviewer's ticks, its live build and log, its question if it's blocked, and a bar at the bottom with Ship, or Set ready for a draft. A ticket whose criteria changed says which ones and how, without you opening its review pack.
- **Decided for you, as speck's report.** The calls speck made for you this week, each with the question, what it went with and what it turned down, so you can change any you'd have called differently before it ships.
- **The Pipeline log as a page.** Filters for decisions, ships and builds, the manager's own lines marked with its face, and every line shown whole.
- **The bridge.** With panels running for two or more projects, All projects in the project menu shows everything that needs you across them, with this week's shipped tickets, build time and spend, and takes you to any ticket in its own project.

## What's changed

- **A new look.** New colours and type in both looks, with fonts that come with the panel, so it looks the same with no network. Settings, buttons, build logs and review packs match it.
- **Steadier `speck run`.** A resume the watch agent asked for is dropped if the ticket moved on while it waited for a slot, instead of restarting the build on a stale instruction. A panel a build starts, for example to take pictures, stays out of your project menu and is stopped when the build ends, and your own panels are never touched.
- **The README tells the 1.0 story,** with new demo pictures of the redesigned panel.

The shipped price table has this release's rates. Costs speck works out from tokens are still estimates at API list prices, so they can differ a little from what you were billed.

## Update

Paste the setup prompt from the README into your coding agent, or run this in each project's folder:

```sh
npx github:luroai/speck#v1.0.0 init
```

Then, to name your engineering manager, type a name under Your engineering manager in the panel's Settings view, or run `speck config set speck_name "<name>"`.

## Upgrading from 0.22.0

- Run `npx github:luroai/speck#v1.0.0 init` again in each project to update the speck command and skills. It keeps your config and tickets. The new skills are what let a build list the options it doesn't recommend, and tell builders to stop a panel by its port.
- The LCD screen is gone, with its clock and speck's old animations. Everything it did is in the black bar: press its status for the Pipeline log, and switch projects from the project's name.
- `speck_name` is a new setting, `speck` until you change it, so nothing reads differently until you name it. The Settings group that was Watching is now Your engineering manager, with the same `watch` settings.
- Lines `speck run` writes about its engineering manager now say "I", and start with a small » mark in a terminal. Lines written before this stay as they were.
- The bridge reads every project's panel, so update each project to 1.0.0: a project on an older speck shows there as not answering.
- If you added the panel to a phone's home screen, add it again to pick up the new icon.
- There are no settings to change in `speck/config.yml`.

See everything that's changed in the [1.0.0 section of the changelog](https://github.com/luroai/speck/blob/v1.0.0/CHANGELOG.md#100--10-november-2026).
