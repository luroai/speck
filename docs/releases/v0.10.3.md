0.10.3 is a bug-fix release, with small additions to setup and the panel's Settings view. It changes nothing you need to set up: closing a laptop's lid during a build no longer adds hours to its time, and `speck run` no longer restarts a build over and over while the Foreman waits for your answer about it.

## What's fixed

- **Time asleep isn't build time.** While `speck run` is on, the time the machine spends asleep during a build, such as with a laptop's lid closed, is left out of the build's time, and `speck run`'s log says how long it was asleep. Before, a build could show hundreds of minutes after a night with the lid shut, which skewed the panel's Shipped figures and the README's "Built with speck" figures. This works on Linux. On a Mac, speck reads the sleep and wake times the Mac records, which haven't been tried on a real Mac yet.
- **No more restarts while the Foreman waits for you.** When a build ends with its ticket still ready, a note or question the Foreman adds to the ticket no longer starts the build again. Before, each question restarted the build, which stopped at the same unanswered question, so the Foreman asked again, costing a build's tokens each time. Setting the ticket ready again, or editing it yourself, still starts it again.
- **Cursor as a reviewer in Settings.** The Settings view offers `cursor` as a reviewer when Cursor is installed and signed in, and its `reviewer_model` is a list of Cursor's models rather than a box where you had to type each model's exact name.
- **The Foreman's model from a list.** `foreman_model` in the Settings view is a list of the models of the agent the Foreman runs on, rather than a box to type in.
- **Tests first in an existing folder.** In a folder with code but no tests, setup offers a first ticket that sets up tests for that code, so your first feature ticket doesn't have to, which would make it slow. It's left as a draft for you to approve.

## Update

Paste the setup prompt from the README into your coding agent, or run this in your project's folder:

```sh
npx github:luroai/speck#v0.10.3 init
```

## Upgrading from 0.10.2

- Run `npx github:luroai/speck#v0.10.3 init` again in each project to update the speck command and skills. It keeps your config and tickets.
- There are no new settings, so nothing needs adding to `speck/config.yml`.
- A `speck run` that's already on keeps its old code until it switches by itself, so until then it still counts time asleep as build time.
- Tickets already recorded with time asleep in them keep it, and builds started by hand with `speck run` off still count it.
- When the machine sleeps during a build, `speck run` commits the time asleep to the ticket in its build's folder, as `speck(<id>): time asleep`.
- When Cursor's or the Foreman agent's models can't be read, the setting is a box to type in, as before, with one line saying why.

See everything that's changed in the [0.10.3 section of the changelog](https://github.com/luroai/speck/blob/v0.10.3/CHANGELOG.md#0103--20-october-2026).
