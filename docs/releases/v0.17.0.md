0.17.0 joins up your projects. When more than one speck project has its panel running on the same computer, you can now switch between them from any panel's header, without leaving the address you have open, so one bookmark or one home-screen app reaches them all. Swiping between lanes is quicker too.

## What's new

- **Switch projects from the header.** With two or more panels running, a small arrow beside the project's name lists every running project. Pick one and its panel shows at the address you're on, including the phone's home-screen app and a `--url` address. Before, each project had its own address and its own app, and there was no way to get from one project's panel to another's.
- **Each project is still its own.** The panel you picked works as if you'd opened it directly, and its buttons and Settings change only that project. Only the running panels in the list can be reached this way, and each still needs its own key, so the switcher doesn't open your panels to anything else.
- **A list that keeps up.** A panel you start with `speck panel` appears in the list within 10 seconds, and one that stops leaves it within 10 seconds, with no reload. If the project you're looking at stops, a notice says so, and the arrow still takes you to the others.
- **Snappier lane swipes.** A trackpad swipe changes lane after half the distance it needed before, the new lane slides into place in a little over half the time, and the slide no longer waits for the lists to redraw. Before, moving between Plan, Build and Shipped still felt slow, especially with a long Shipped list.

## Update

Paste the setup prompt from the README into your coding agent, or run this in each project's folder:

```sh
npx github:luroai/speck#v0.17.0 init
```

## Upgrading from 0.16.1

- Run `npx github:luroai/speck#v0.17.0 init` again in each project to update the speck command and skills. It keeps your config and tickets.
- The project switcher lists only projects updated to 0.17.0 whose panel is running. A project still on 0.16.1 or earlier doesn't appear until you update it. A panel that's already running picks up the new code by itself.
- There are no new settings, so nothing needs adding to `speck/config.yml`.
- A trackpad swipe now changes lane after a shorter sideways movement, so a small sideways nudge while scrolling a list is more likely to change lane.

See everything that's changed in the [0.17.0 section of the changelog](https://github.com/luroai/speck/blob/v0.17.0/CHANGELOG.md#0170--26-october-2026).
