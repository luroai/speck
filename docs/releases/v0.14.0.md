0.14.0 is a minor release that adds model providers, through your own API key for each. DeepSeek is the first, and the only one tested with speck so far. Save this machine's DeepSeek key once, and DeepSeek can build your tickets, review them and run the Foreman, so you can pick a model that may be cheaper or quicker for the work. Nothing changes unless you choose it.

## What's new

- **Keep a provider's API key safely.** `speck keys set deepseek` asks for the key without showing it and keeps it for this machine only, in a file git ignores and only you can read. Every worktree uses the same key, speck never prints or logs it, and `speck keys` only says whether it's set. `speck keys remove deepseek` deletes it.
- **Review with DeepSeek.** With `reviewer: deepseek`, review rounds run on DeepSeek's model, read-only, as the Claude reviewer's do. DeepSeek counts as a family of its own, so it can review any builder's work, Claude Code's included.
- **Build with DeepSeek.** With `builder: deepseek`, `speck run` builds tickets on DeepSeek's model. Each build follows the same steps as a Claude Code build, and stopping, resuming and handing a ticket back work the same.
- **Run the Foreman on DeepSeek.** With `foreman: deepseek`, or a blank `foreman` while DeepSeek builds, the Foreman looks into stops on DeepSeek's model, allowed to do only what it always could.
- **Choose it in Settings.** The builder, reviewer and Foreman lists offer DeepSeek with its models, and an API keys box says whether this machine has its key and lets you enter or replace it, without a commit and without ever showing a saved key.

DeepSeek runs through your own DeepSeek API key. Claude Code must be installed, but it only gets DeepSeek's address and your DeepSeek key: nothing is sent to Anthropic, and your Claude sign-in, your own Claude Code settings and your connectors aren't used. Without the key or Claude Code, nothing starts, speck says why and how to fix it, and `speck doctor` checks both when DeepSeek builds or reviews.

## Update

Paste the setup prompt from the README into your coding agent, or run this in each project's folder:

```sh
npx github:luroai/speck#v0.14.0 init
```

## Upgrading from 0.13.1

- Run `npx github:luroai/speck#v0.14.0 init` again in each project to update the speck command and skills. It keeps your config and tickets.
- No settings or commands are renamed or removed. `speck keys` is new, and `builder`, `reviewer` and `foreman` accept `deepseek`. Until you choose DeepSeek, everything works as it did.
- `speck config set builder deepseek` sets `build_command` blank in the same change, as switching the builder in Settings does.

See everything that's changed in the [0.14.0 section of the changelog](https://github.com/luroai/speck/blob/v0.14.0/CHANGELOG.md#0140--23-october-2026).
