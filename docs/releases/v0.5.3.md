0.5.3 is a patch release so that `speck run` runs its newest code by itself: when a change to speck ships while `speck run` is on, it's live without anyone turning `speck run` off and on.

## What matters most

- **`speck run` switches to its new code once it's idle.** Before, `speck run` kept running the code it started with, so a shipped change to it wasn't live until someone turned it off and on, and nothing said so. Now it notices the change, starts no new build or ship, says once which builds and ships it's waiting for, and switches to the new code as soon as they've ended. It carries on in the same terminal or panel log, the panel's Auto-build switch stays on throughout, and Ctrl+C still stops it. If the new code can't start, it says why once and keeps going on its old code until the next change. A paused build counts as running, so it holds up the switch until it's played or stopped.

## Install

Paste the setup prompt from the README into your coding agent, or run this in your project's folder:

```sh
npx github:luroai/speck#v0.5.3 init
```

## Upgrading from 0.5.2

- Run `npx github:luroai/speck#v0.5.3 init` in your project to update the speck command and skills. It keeps your config and tickets.
- If `speck run` is on when you upgrade, it's still running 0.5.2's code, which can't switch by itself, so turn it off and on once afterwards. From then on it switches by itself.
- Nothing in `speck/config.yml` needs changing.

See everything that's changed in the [0.5.3 section of the changelog](https://github.com/luroai/speck/blob/v0.5.3/CHANGELOG.md#053--16-october-2026).
